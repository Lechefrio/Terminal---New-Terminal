# F1 Pick 10th v2 Frontend

Modern React + Vite frontend for the F1 Pick 10th fantasy game.

## Local setup

```bash
npm install
npm run dev
```

## Netlify settings

- Build command: `npm run build`
- Publish directory: `dist`

Add this environment variable in Netlify:

```bash
VITE_API_BASE_URL=https://YOUR-CURRENT-NETLIFY-SITE.netlify.app/.netlify/functions
```
